# Creator operating process

Use this when ideas, requests, or opportunities come in quickly.

## Capture

Write every idea in one line before judging it.

Template:

- Idea:
- Source:
- Buyer/problem:
- Can it become a service, product, or video?
- What proof do I already have?

## Filter

Score each idea from 0 to 2.

| Question | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Can I make it without spending money? | No | Maybe | Yes |
| Can I finish a first version with existing assets? | No | Partly | Yes |
| Does it solve a buyer problem? | No | Unclear | Yes |
| Can it become more than one asset? | No | Maybe | Yes |
| Can I show proof? | No | Some | Yes |

Decision:
- 8-10: produce now.
- 5-7: rewrite the offer and test interest.
- 0-4: park it.

## Produce

Every product or service starts with one clear deliverable.

Required:
- Title
- Buyer problem
- Deliverable
- Price
- One proof asset
- One risk/disclaimer

Do not add extras until the first version is published.

## Publish

Publish in this order:

1. Gumroad draft or Fiverr gig draft.
2. One proof screenshot or short video.
3. One social post or YouTube short pointing to the offer.
4. Tracking note: date, clicks, questions, sales.

## Review

After each signal, ask:

- Did anyone click?
- Did anyone ask a question?
- Did anyone buy?
- What confused them?
- What would make the offer easier to trust?

Only change one thing at a time: title, thumbnail, price, or deliverable.

## Stop rules

Stop or park an idea when:

- It requires paid tools before there is demand.
- It needs a full game launch before it can earn anything.
- It cannot be explained in one sentence.
- It creates anxiety but no buyer-facing deliverable.

## Default focus

When unsure, return to this sequence:

1. Roblox Economy Audit Template
2. Fiverr audit gig
3. Gumroad starter kit
4. Short proof video
5. Palm Luxe Tycoon case study
