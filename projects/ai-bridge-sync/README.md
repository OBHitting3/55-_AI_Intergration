# AI Bridge Sync

Iron Forge Studios MCP-only dashboard: validate LLM target configs, MCP health checks, sync history, Airtable webhooks.

**Status:** active

**Path:** Repository root (`src/`, `package.json`)

## Run

```bash
cp .env.local.example .env.local
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm run type-check
```
